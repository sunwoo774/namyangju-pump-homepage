# 남양주 한일윌로모터펌프 - 파워펌프 서비스센터

남양주 지역 지하수 모터펌프, 배수펌프, 심정펌프, 압력탱크, 동파 출장수리 전문 웹사이트입니다.
기존 "파워펌프(가평)"·"홍천" 홈페이지와 색상/레이아웃/구성을 차별화해 제작했습니다.

## 이 사이트만의 차별점

- **톤**: 차콜 다크 + 시그널 오렌지 + 모노스페이스 숫자. (가평=네이비/골드, 홍천=딥그린/코랄·세리프)
- **레이아웃**: 카드 나열형 대신 "증상 자가진단" 클릭형 위젯을 시그니처로 배치. 서비스는 카드가 아닌 연결선이 있는 타임라인(STEP 01~04)으로 구성.
- **출장 권역**: 표(홍천) 대신 동심원 다이어그램으로 시각화. 기준점은 매장 소재지(양평)이며, 실제 이동 거리에 맞춰 권역별 소요시간을 정직하게 안내.
- **콘텐츠 강조점**: 산간·펜션 중심인 기존 두 사이트와 달리, 서울 접근성·신도시 아파트 상가·공장/비닐하우스·배수펌프 등 남양주 특성을 반영.

## 변경 이력 (2차 수정)

1. 사이트명을 "남양주 한일윌로모터펌프"로 변경 (title, 헤더, JSON-LD, 푸터 전체 반영).
2. 출장권역 기준점을 "양평 매장 출발"로 재정렬. 와부·조안(30~40분) → 화도·수동·진건·퇴계원(40~60분) → 다산·별내·진접·오남(남양주 서부, 상주 기사 협업) 순으로 실제 거리에 맞게 재배열.
3. "기지" 표현을 전부 "매장"으로 변경 (권역 다이어그램 중심 라벨 포함).
4. "대응 가능 심도 80m" 문구를 신뢰도 있는 배지형 컴포넌트로 교체 — 아이콘 + 큰 숫자(80m) + "아파트 27층 높이" 비교 문구로 재구성.
5. 출장지역에 이천시·여주시·경기도 광주시 추가 (권역 목록, 푸터, JSON-LD areaServed).
6. "배수펌프" 섹션 신설 — 아파트·상가 지하 피트 배수펌프 증상/서비스(자동교대운전, 플로트스위치 점검 등) 안내, 실제 현장 사진 포함.
7. 업로드된 수중모터/배수펌프 현장 사진 4장을 작업 사례·배수펌프 섹션에 반영 (`images/media/case-motor-lift-yard.jpg`, `case-motor-lift-closeup.jpg`, `case-drain-pump-pit.jpg`, `case-drain-pump-install.jpg`).

## 로컬 미리보기

```bash
python3 -m http.server 8000
# 또는
npx serve .
```

브라우저에서 `http://localhost:8000` 으로 접속하세요.
